# Gahui Kim Academic Portfolio

A static, responsive academic portfolio website.

## Preview locally

From this directory, run:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Publish

The site can be published directly with GitHub Pages, Netlify, Cloudflare Pages, or another static host. Keep `index.html`, `styles.css`, `script.js`, and the `assets` folder together.

## Update the CV

Replace `assets/Gahui_Kim_CV.pdf` with a new version using the same filename.
